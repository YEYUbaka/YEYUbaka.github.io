# YEYUbaka.github.io

YEYUbaka 的个人作品集网站，定位为：

> AI 专业学生｜测试开发方向｜Python 实践者

网站采用深色极简科技风，展示真实公开项目、当前学习方向和联系方式。

## Local development

~~~powershell
npm install
npm run dev
~~~

## Verification

~~~powershell
npm test
npm run build
npm run preview
~~~

## Featured projects

首版精选项目固定为：

1. [LocalRAG](https://github.com/YEYUbaka/LocalRAG)：本地优先的 RAG 个人知识库系统。
2. [AI-learning-companion](https://github.com/YEYUbaka/AI-learning-companion)：AI 个性化学习平台。
3. [doubanspider](https://github.com/YEYUbaka/doubanspider)：豆瓣电影信息爬取、分析与可视化项目。

项目描述只引用公开仓库中可以核验的事实，不写入未经验证的评测数字或虚构演示地址。

## Deployment

推送到 main 后，GitHub Actions 会执行测试、构建并部署 dist 到 GitHub Pages。仓库的 Pages 发布源需要在 GitHub 设置中选择 GitHub Actions。
